# Currículo – Marty McFly

Página de currículo responsiva feita com HTML5, CSS3 e Vue 3, baseada em um layout do Figma.

🔗 **Demo:** https://pedroemanuel16.github.io/projeto-curriculo/

## Tecnologias

- HTML5
- CSS3
- JavaScript + Vue 3
- Fontes IBM Plex Sans e IBM Plex Mono

## Estrutura

```
├── index.html   # estrutura da página
├── style.css    # estilos e responsividade
└── app.js       # dados do currículo e app Vue
```
